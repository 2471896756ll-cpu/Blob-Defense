# 操作与玩法说明

## 目标

保护城堡，阻止敌方 Blob 到达进攻区域。城堡生命归零或玩家死亡时，本局结束。

## 开始一局

1. 运行 `FirstProject.exe`，在主菜单选择“开始游戏”。
2. 进入关卡后，在准备时间内规划防御位置。
3. 按 R 打开部署菜单，用滚轮或鼠标中键选择设施。
4. 用鼠标左键进入购买/放置流程，瞄准合适地面后确认放置；右键取消。
5. 倒计时结束后抵挡敌人，击杀获得金币，再部署更多防御。

## 防御设施

| 设施 | 作用 |
| --- | --- |
| 基础炮台（橙色） | 稳定攻击单个敌人，适合起步 |
| 速射炮台（绿色） | 更频繁地射击，压制靠近的敌人 |
| 榴弹炮台（蓝色） | 发射弹跳榴弹，直接命中 Blob 时爆炸并造成范围伤害 |
| Blob 巢穴 | 定期生成友方 Blob，巡逻并接近敌人自爆 |

友方 Blob 会随机配色与大小：较大的移动慢、爆炸伤害高；较小的移动快、爆炸伤害低。炮台默认攻击敌方 Blob，玩家默认不能用枪摧毁友方炮台。

## 敌人与金币

普通敌人沿路线攻向城堡；阿尔法 Blob 在玩家接近后会追击玩家。每波末尾还有一只戴王冠、体型更大的敌人。

默认每只有效击杀的金币奖励：

| 波次 | 金币 |
| --- | --- |
| 1～2 | 25 |
| 3～4 | 20 |
| 5～6 | 15 |
| 7～8 | 10 |
| 9 及以后 | 5 |

波次之间有准备时间。具体初始资源、敌人数量和设施价格以试玩版本的实际界面为准。

## 暂停、设置与失败

- 按 **P** 暂停或恢复，设置里可调整画面、语言、音乐、枪与炮台声音。
- 枪和炮台的可爱音效开关彼此独立，关闭对应开关可恢复原音色。
- 失败后世界暂停，可选择重新开始、返回主菜单、退出或隐藏菜单自由观察；按 P 返回结果菜单。
- 游戏目前不提供中途存档，重新开始会重置本局进度。
