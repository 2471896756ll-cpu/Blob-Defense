# 运行常见问题

## 我需要安装 Unreal 吗？

不需要。试玩包是独立的 Windows 64 位游戏。

## 下载仓库 ZIP 后为什么没有 exe？

这个仓库存放展示资料，游戏程序需要从 Releases 的试玩附件下载。没有发布附件时，说明试玩包尚未上传。

## 分卷压缩包如何解压？

若发行版采用分卷压缩，请下载所有分卷，放在同一文件夹，使用支持该格式的解压工具从第一卷开始解压，再运行最外层的 FirstProject.exe。不要尝试单独解压后面的分卷。

## 提示缺少 VCRUNTIME140 或 MSVCP140

完整解压后，安装 Prerequisites 文件夹中的 VC_redist.x64.exe，再启动游戏。

## 游戏文件夹中哪些文件能删除？

试玩时保留整个解压目录。Engine、FirstProject 和数据文件均可能是运行必需内容，不能只拿走 exe。

## 黑屏、闪退或运行缓慢

先确认文件已完整解压、运行库已安装、显卡驱动可用；进入设置降低画面质量后再试。不同电脑的兼容性仍在测试中，尚无经过验证的最低配置表。

## 暂停键是什么？

使用 P。进入关卡后先点击游戏画面取得焦点；若仍无法操作，请在 Issues 说明游戏版本以及具体失效的按键。

## 能多人联机、在手机或浏览器直接玩吗？

目前提供 Windows 单人体验，尚未提供多人联机、移动端或网页版本。
